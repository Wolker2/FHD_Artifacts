# FHD_Artifacts — Space Rangers HD

Мод FHD_Artifacts для Space Rangers HD: A War Apart / Космические рейнджеры HD: Революция.

## Версия 0.8.24.2 (TEST)

- [Готовый установочный ZIP](FHD_Artifacts_0.8.24.2_TEST_SMART_MAGNET_CARGO_LIMIT.zip)
- [Отдельная папка исходников для Nexus / GitHub](FHD_Artifacts_0.8.24.2_TEST_SMART_MAGNET_CARGO_LIMIT_Nexus-GitHub)
- [Сборщик](FHD_Artifacts_0.8.24.2_TEST_SMART_MAGNET_CARGO_LIMIT_Nexus-GitHub/BUILD.py)
- [README на русском](FHD_Artifacts_0.8.24.2_TEST_SMART_MAGNET_CARGO_LIMIT_Nexus-GitHub/README_RU.md)

В папке исходников сохранён исходный ZIP и доступны редактируемые TXT/INI, оригинальные DAT/BMP, 40 изображений PNG и 39 кадров анимации PNG. Контрольные суммы позволяют пересобрать исходный ZIP без изменений. Исходники DLL отсутствуют, представлены только готовые бинарные файлы. Полный игровой тест этой публикации не проводился.

Библиотечные компоненты XenoNative и системные DLL присутствуют в оригинальном установочном архиве, поэтому перед установкой необходимо проверить существующие файлы игры.
